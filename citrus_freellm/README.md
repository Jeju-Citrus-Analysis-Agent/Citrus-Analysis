# 감귤의 신(神): 데이터로 읽는 제주 감귤 수급 비서

제주 감귤의 생산량·가격·경영비 자료를 질문으로 찾아보고 계산하는 도우미입니다.
숫자는 모두 로컬의 정제 데이터에서 코드가 계산합니다. 모델은 숫자를 만들지 않습니다.

## 실행

Python 3.10 이상, 프로젝트 루트에서 실행합니다.

```powershell
python -m pip install -r citrus_freellm/requirements-ui.txt
python -m streamlit run citrus_freellm/web.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```

Windows에서는 `.\citrus_freellm\start-web.cmd`로도 띄울 수 있습니다. 준비된 `.venv-agent`가 있으면 그 환경을 씁니다.
주소는 http://127.0.0.1:8501 입니다.

```powershell
.\citrus_freellm\start-agent.cmd                                                     # 터미널 대화
.\.venv-agent\Scripts\python.exe -m citrus_freellm "천혜향 생산량을 그래프로 보여줘"  # 질문 한 번
.\.venv-agent\Scripts\python.exe -m citrus_freellm --diagnose                       # 실행 환경 점검
```

## 상담 모드 (Claude, Anthropic API 키)

상담 모드에는 Anthropic API 키로 Claude Haiku 5.5(`claude-haiku-5-5`)를 연동해 썼습니다.
`citrus_freellm/.env.example`을 `.env`로 복사하고 `ANTHROPIC_API_KEY`에 키를 넣으면 켜집니다.
키 값은 `.env`에만 두고 Git에는 올리지 않습니다.

- '2024년 천혜향 생산량'처럼 형식이 분명한 질문은 모델을 거치지 않고 로컬 규칙이 바로 답합니다.
- '감귤 사업 유망한가요?'처럼 규칙이 못 알아듣거나 자기 상황을 묻는 질문은 Claude가 맡습니다.
  목적·재배 방식·품종·자본 규모를 기억하고, 필요할 때 선택지 버튼으로 되묻습니다.
- Claude는 검증된 로컬 조회를 거쳐서만 숫자를 얻습니다. 답에 조회 결과에 없는 숫자가 있으면
  다시 쓰게 하고, 그래도 남으면 검증 결과만 보여 줍니다.
- 사용자가 적은 금액은 '1억~3억 원' 같은 구간으로 바꿔서 보냅니다.
- 관세·농지 가격·스마트팜 설치비·가공업 수익·주식은 자료가 없다고 답합니다.
- 모델 호출이 실패하면 로컬 답변을 보여 줍니다. 구현은 `consult.py`, 프롬프트는 `consult.py`의 `PROMPT`입니다.

키가 없으면 상담 모드만 꺼지고 나머지 기능은 그대로 동작합니다.

## 화면 사용법

로고 아래 버튼 줄에서 새 대화, 예시 질문, 리포트, 사용 안내를 엽니다.
예시 질문은 하고 싶은 일별로 묶여 있습니다. [카테고리별 쉬운 질문](docs/TOOL_QUESTIONS.md)

- 답은 결론을 먼저 쓰고, 표·그래프·출처를 그 아래에 둡니다. 터미널과 리포트도 같은 순서입니다.
- 표가 나온 뒤 '그래프로 그려줘'라고 하면 같은 수치로 그래프를 그립니다.
  '막대그래프로 바꿔줘'처럼 막대·꺾은선·영역·점 그래프로 모양을 바꿀 수 있습니다.
- 질문 아래 '수정하기'로 질문을 고치면 그 질문부터 다시 답하고, 뒤에 이어진 대화는 지웁니다.
- 큰 숫자는 '만·억' 단위로 풀어 주고, 답에 나온 단위(톤, ha, 원/kg 등)만 설명합니다.
- 리포트는 Markdown과 PDF로 받습니다. 끝의 '출처 기록'에 출처와 파일 해시(sha256)가 들어갑니다.
  PDF에는 한글 글꼴이 필요합니다. 나눔고딕·맑은 고딕을 찾지 못하면 `CITRUS_PDF_FONT`로 지정하고, 없으면 Markdown만 만듭니다.

## 자료와 지원 범위

- 생산 통계: `data/raw/public/fruit_production.csv`(2015~2020년)와 수급센터 품종별 통계(2004~2025년).
- 그 밖에 월별 기상, 국가별 수출, 가공, 일별 가격, 월별 출하 자료를 조회합니다. 실제 기간은 '어떤 데이터가 있어?'로 확인합니다.
- 비교할 때는 비교 연도와 공통 항목 수를 함께 보여 주고, 빠지거나 중복된 값은 빼거나 보류합니다.
  기온은 ℃ 차이, 가공률은 퍼센트포인트 차이로 비교합니다.
- 파일에 없는 기간은 채워 넣지 않습니다. 2017년 재배면적 통계 단절을 가로지르는 비교도 하지 않습니다.
- 날씨와 생산량·가격의 관계는 작은 표본의 상관계수라, 원인이나 미래 값으로 답하지 않습니다.
- 경영비·소득은 표준소득표(표본 농가, 10a당) 기준입니다. 소득은 순이익이 아니고, 만감류는 제주 평균 농가보다 높게 나옵니다.
- 표준소득표·CPI 파일은 jasdc 간행물 자료라 Git에 없습니다. 팀 공유 data 폴더가 있어야 조회되고, 없으면 해당 테스트는 건너뜁니다.
- 인터넷 검색은 질문에 '인터넷에서 찾아줘'라고 적을 때만 하고, 공공기관 도메인만 보여 줍니다.
- 문서 검색은 README, docs, 공개 분석 근거 Markdown만 대상으로 합니다.

원본 CSV는 읽기만 하고, 질문으로 코드나 임의의 파일 경로를 실행하지 않습니다.
`.env`, 로그, 리포트, 가상환경은 Git에서 제외합니다. 참조 저장소 위치는 `CITRUS_REPO_PATH`로 바꿀 수 있습니다.

## 출처

답변의 출처 링크는 루트 `README.md`에 적은 출처를 따릅니다. 과수 통계는 제주데이터허브,
감귤 통계는 제주농산물수급관리센터, 유통처리 자료는 해당 유통처리 상황 화면으로 연결합니다.
원문 URL이 없는 자료는 추정 출처라고 표시합니다. 파생 자료는 원자료까지 거슬러 올라가 집계·정제 과정을 밝힙니다.

날씨는 [기상청 ASOS 일자료](https://data.kma.go.kr/data/grnd/selectAsosRltmList.do?pgmNo=36)를 내려받아 월별로 집계했습니다.

## 경영비·물가 보정·손익분기 (노트북 03·04)

- 표준소득표(`data/external/cost/standard_income.csv`, 2016~2024년산)의 경영비·소득·생산비·순수익, 품종 순위,
  CPI 실질화, 손익분기 단가(경영비÷수량, 생산비÷수량)를 조회합니다. 조회할 때마다 소득·순수익·단위를 검산합니다.
- 노트북 03·04의 결론은 고정 커밋 발췌(`knowledge/sources/cost_analysis.md`)와 카드 6개로 설명합니다.
- 질문 예시: [경영비·물가 보정·손익분기 질문](docs/TOOL_QUESTIONS.md#경영비물가-보정손익분기-질문-노트북-0304)
