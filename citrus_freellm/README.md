# 감귤의 신 (神) : 데이터로 읽는 제주 감귤 수급 비서

API 키 없이 통계 조회·계산과 10가지 추가 도구를 사용합니다.
키가 없으면 모델 API를 호출하지 않으며 `.env`와 인터넷 연결이 필요 없습니다.
(질문에 ‘인터넷에서 찾아줘’라고 직접 적을 때만 공공기관 검색 링크를 찾으려고 인터넷을 씁니다.)

## 맞춤 상담 (선택, Claude)

`citrus_freellm/.env`에 `ANTHROPIC_API_KEY`를 넣으면 웹 화면에서 상담 모드가 켜집니다
(기본 모델 `claude-haiku-5-5`, `.env.example` 참고).

- 정해진 형식의 질문(예: ‘2024년 천혜향 생산량’)은 지금처럼 로컬 규칙이 바로 답합니다.
- ‘감귤 사업 유망한가요?’처럼 규칙이 못 알아듣거나 내 상황을 묻는 질문은 Claude가 맡습니다.
  목적·재배 방식·품종·자본 규모를 기억하고, 필요할 때만 선택지 버튼으로 되묻습니다.
- 숫자는 Claude가 검증된 로컬 조회를 거쳐서만 얻습니다. 답의 모든 숫자가 조회 결과에 있는지
  자동으로 대조하고, 없는 숫자가 있으면 다시 쓰게 하거나 검증 결과만 보여 줍니다.
- 사용자가 적은 금액은 컴퓨터 밖으로 보내지 않고 ‘1억~3억 원’ 같은 구간으로 바꿔 보냅니다.
- 관세·농지 가격·스마트팜 설치비·가공업 수익·주식은 자료가 없다고 안내합니다.
- 모델 호출이 실패하면 로컬 답변을 그대로 보여 줍니다. 구현: `consult.py`

## 왜 LLM 없이 답하나

이 에이전트는 **숫자를 만들어 내지 않는 것**을 가장 중요한 조건으로 둡니다.
농가가 판단에 쓰는 생산량·단가·소득은 한 자리만 틀려도 잘못된 결정으로 이어지기 때문입니다.

- 모든 수치와 결론 문장은 등록된 원자료에서 코드가 계산합니다. 원자료 대조(`reference_check.py`)를 통과하지 못하면 답하지 않습니다.
- 질문 해석(“그 전해는?”, “면적만 빼고”, “두 해 차이는?”)도 규칙으로 처리합니다.
  `evaluation_cases.json`의 대화 평가 10개를 **모델 없이 10/10** 통과합니다 (`tests/test_followup_phrasing.py`).
- 선택적 모델 연결(`client.py`, `intent.py`)은 남아 있습니다. 연결해도 모델은 질문 해석 후보만 제안하고,
  수치·답변 문장은 지금과 같은 검증 코드가 만듭니다.
- 답할 수 없는 질문에는 추측하지 않고, 실제로 실행해 답이 확인된 관련 예시 질문을 버튼으로 보여 줍니다.

날씨 자료의 원출처는 [기상청 ASOS 일자료](https://data.kma.go.kr/data/grnd/selectAsosRltmList.do?pgmNo=36)입니다.
포털에서 ‘일’ 자료와 관측 지점·기간을 선택할 수 있습니다. 프로젝트의 월별 날씨는 내려받은 일자료를 집계한 값입니다.

답변의 데이터 출처 링크는 저장소 루트 `README.md`에 기재된 출처를 따릅니다.
과수 통계는 제주데이터허브, 감귤 통계는 제주농산물수급관리센터,
유통처리 자료는 해당 유통처리 상황 화면을 연결합니다.
추정 출처와 원문 URL이 없는 자료는 그 상태를 표시합니다.
분석 문서와 실제 사용 파일·해시 기록도 함께 보존합니다.
파생 자료는 원자료까지 출처를 추적하고 집계·정제 과정을 설명합니다.
표가 포함된 답변 다음에 “그래프로 그려줘”라고 입력하면 앞선 표의 항목·기간·수치를 그대로 그래프로 표시합니다.
여러 지표는 그래프를 나누어 표시하며 “선 그래프로 보여줘”, “막대 그래프로 그려줘”도 지원합니다.
답변에는 원문 링크를 표시하며 CSV 파일명·경로는 내부 검증 기록에만 남깁니다.

## 테스트

프로젝트 루트에서 한 번에 실행합니다 (데이터 정제 테스트 + 에이전트 테스트).

```powershell
python -m pip install -r requirements.txt -r citrus_freellm/requirements-ui.txt pytest
python -m pytest
```

## 실행

Python 3.10 이상이 필요합니다. 프로젝트 루트에서 실행하세요.

```powershell
python -m pip install -r citrus_freellm/requirements-ui.txt
.\citrus_freellm\start-web.cmd
```

웹 주소: http://127.0.0.1:8501

배치 파일은 준비된 `.venv-agent` 환경이 있으면 자동으로 사용합니다.

```powershell
# 터미널 대화
.\citrus_freellm\start-agent.cmd
# 질문 한 번만 실행
.\.venv-agent\Scripts\python.exe -m citrus_freellm "천혜향 생산량을 그래프로 보여줘"
# 로컬 실행 환경 확인
.\.venv-agent\Scripts\python.exe -m citrus_freellm --diagnose
```

그래프는 웹 화면에서 표시됩니다. 터미널과 리포트에는 같은 수치 표가 남습니다.
`--offline` 옵션은 이전 실행 명령과의 호환을 위해 유지합니다.

## 사용 방법

왼쪽 **예시 질문 → 무엇을 하고 싶으세요?**에서 원하는 일을 고르고 질문을 누르거나 직접 적어 주세요.
예: ‘안녕’, ‘2020년 제주 날씨 보여줘’, ‘천혜향 생산량을 그래프로 보여줘’.

[9개 예시 카테고리와 쉬운 질문 18개](docs/TOOL_QUESTIONS.md)

답변은 **결론 → 세부 설명** 순서입니다. 결론 다음에 표·그래프·출처를 바로 보여줍니다.
터미널과 리포트에도 같은 순서를 적용합니다.

- **후속 질문:** ‘그래프로 그려줘’처럼 질문창에 직접 입력하세요. 그래프·연도 비교 버튼은 표시하지 않습니다.
- **질문 위치로 이동:** 직접 입력, 예시 질문, 후속 질문, 질문 수정 모두 해당 질문 위치로 이동하도록 합니다.
- **조회 가능 기간:** 화면 위에 생산 통계 기간을 표시합니다. 다른 자료는 ‘어떤 데이터가 있어?’로 확인하세요.
  파일이 바뀌면 안내도 갱신합니다. 표시한 기간 안의 누락 여부는 조회할 때 다시 확인합니다.
- **질문 수정:** 질문 아래 작은 ‘수정하기’를 누르면 그 자리에서 질문을 고칠 수 있습니다.
  저장하면 해당 질문과 답변을 바꾸고 뒤에 이어진 대화와 해당 리포트 결과를 정리합니다.
  수정 전까지의 대화와 이미 다운로드한 파일은 남습니다. ‘취소’를 누르면 바꾸지 않습니다.
- **숫자·단위 도움말:** 질문에 답할 때 큰 숫자를 ‘만·억’ 단위로 풀어 보여주고,
  해당 답변에 쓰인 톤·ha·원/kg 등의 단위만 함께 설명합니다. 원래 수치와 단위는 유지합니다.
- 사이드바에는 대화·리포트, 사용 안내, 카테고리별 예시 질문을 제공합니다.
리포트 만들기를 누르면 Markdown과 PDF로 다운로드할 수 있습니다. 출처·파일 버전(sha256)은 리포트 끝의 ‘출처 기록’에 들어갑니다.
PDF는 한글 글꼴(나눔고딕·맑은 고딕 자동 탐색, 또는 `CITRUS_PDF_FONT`)이 필요하며, 없으면 Markdown만 만듭니다.
리포트에는 그래프의 수치 표가 포함됩니다.

## 자료와 지원 범위

- 원자료 생산량·생산면적 조회: `data/raw/public/fruit_production.csv`, 2015~2020년.
- 기존 조회: 연도 비교, 같은 집계수준의 품종 비교·순위·연도 평균.
- 추가 자료 조회: 등록된 월별 기상·국가별 수출·가공·일별 가격·월별 출하 CSV.
- 비교 가능한 조회에는 추가 비교를 제공합니다. 생산량의 가까운 연도 증감, 같은 월의 날씨,
  같은 국가의 수출 증감, 가공량·가공률, 같은 날짜·품종·단위의 가격, 월별 최고·최저 값을 비교합니다.
  비교 연도와 공통 항목 수를 표시하고 누락·중복·불완전 관측은 비교에서 제외하거나 보류합니다.
  기온은 ℃ 차이, 가공률은 퍼센트포인트 차이를 사용하며 의미 없는 증감률을 계산하지 않습니다.
- 판매량·가격·비용을 입력한 이익 계산에는 조건을 고정한 가격 변동 예시를 함께 제시할 수 있습니다.
  인사·문서 검색처럼 수치 근거가 없는 질문에는 비교 값을 만들지 않습니다.
- 파일에 없는 기간은 보간하지 않습니다. 자료 종류와 실제 기간은 ‘어떤 데이터가 있어?’로 확인합니다.
- 생산량은 별도 원자료 검증을 거칩니다. 2017년 면적 통계 단절을 무시해 비교하지 않습니다.
- 날씨 결합은 제주 관측소의 일별 자료가 해당 연도에 빠짐없이 있는지 확인합니다.
- 관계 분석은 작은 표본의 상관계수이며 원인이나 미래값을 확정하지 않습니다.
- 단계별 조사는 정해진 점검 순서를 사용합니다. 자유롭게 계획하는 AI가 아닙니다.
- 인사·용어 설명은 준비된 규칙을 사용하며 일반적인 자유 대화는 지원하지 않습니다.
- 인터넷 검색은 키 없는 공공 웹 검색을 이용하며 공공기관 도메인만 표시합니다.
  검색 서비스 상태에 따라 실패할 수 있고, 그때는 직접 검색 링크를 제공합니다.
- 문서 검색은 README, docs, 공개 분석 근거의 Markdown만 대상으로 합니다.
- 경영비·소득은 표준소득표(표본 농가, 10a당) 기준입니다. 소득은 순이익이 아니며, 만감류는 제주 평균 농가보다 높게 나옵니다.
- 표준소득표·CPI 파일은 jasdc 간행물 자료라 Git에 없습니다. 팀 공유 data 폴더가 있어야 조회가 동작하고, 없으면 해당 테스트는 건너뜁니다.

`CITRUS_REPO_PATH`로 참조 저장소 위치를 지정할 수 있습니다.
원본 CSV는 읽기만 하며 사용자 질문으로 코드나 임의의 파일 경로를 실행하지 않습니다.
`.env`, 로그, 리포트와 가상환경은 Git에서 제외됩니다.
모델 통신 모듈은 이전 코드와의 호환을 위해 남아 있으나 웹·CLI에서는 사용하지 않습니다.

## 경영비·물가 보정·손익분기 (노트북 03·04)

- 숫자 조회: 표준소득표(`data/external/cost/standard_income.csv`, 2016~2024년산)의 경영비·소득·생산비·순수익,
  품종 순위, CPI 실질화, 손익분기 단가(경영비÷수량, 생산비÷수량), 품종별 CPI 실질 단가. 조회 때마다 소득·순수익·단위를 검산합니다.
- 분석 설명: 노트북 03·04의 결론을 고정 커밋 발췌(`knowledge/sources/cost_analysis.md`)와 카드 6개로 제공합니다.
  주제: 경영비를 뺀 품종별 소득, 물가 보정, 손익분기 단가·생산량(약 47만 톤), 소득 변화 분해, 표준표와 제주 평균의 차이, 품종별 경영비 물가.
- 질문 예시는 [도구별 쉬운 질문](docs/TOOL_QUESTIONS.md#경영비물가-보정손익분기-질문-노트북-0304)에 있습니다.
