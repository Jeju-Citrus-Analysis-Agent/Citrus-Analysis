### 경영비·물가 보정·손익분기 질문 (노트북 03·04)

| 하고 싶은 일 | 질문 예 | 답하는 방식 |
|---|---|---|
| 표준소득표 숫자 보기 | 노지온주 경영비 알려줘 / 천혜향 2020년부터 2024년까지 실질 소득 보여줘 | 표준소득표 조회 (검산 후 표) |
| 품종 소득 순위 | 2024년산 품종별 소득 비교해줘 | 표준소득표 조회 + 순위 |
| 손익분기 단가 | 노지온주 손익분기 단가 보여줘 | 경영비÷수량, 생산비÷수량 계산 |
| 물가 보정 단가 | 물가 보정한 노지온주 실질 단가 알려줘 | CPI로 실질화한 표 |
| 비용을 빼면 어떤 품종이 나은가 | 경영비 빼면 어떤 품종이 좋아? | 분석 설명 (03 §1) |
| 가격 상승이 물가 때문인가 | 가격이 오른 건 물가 때문이야? | 분석 설명 (03 §2) |
| 몇 톤 넘으면 적자인가 | 제주 생산량이 몇 톤 넘으면 노지 농가가 적자야? | 분석 설명 (04 §1, 약 47만 톤) |
| 소득이 왜 변했나 | 하우스온주 소득이 왜 줄었어? | 분석 설명 (04 §2, 가격·수량·경영비 분해) |
| 표준표와 제주 평균 차이 | 표준소득표 총수입이랑 제주 평균 차이는? | 분석 설명 (04 §3) |
| 품종별 비용 물가 | 품종별 경영비 물가는 어때? | 분석 설명 (04 §4) |

숫자(판매량·단가·비용)를 함께 적으면 기존처럼 내 농가 가정 계산으로 처리합니다.

## 알아두세요

- 인사·용어 설명은 준비된 답변을 사용합니다. 자유로운 AI 대화는 아닙니다.
- 그래프와 생산량·날씨 결합은 2015~2020년 과수 원자료를 사용합니다.
- 날씨는 제주 관측소 기준입니다. 관계 분석은 원인·미래 예측을 뜻하지 않습니다.
- 단계별 조사는 원자료 확인 → 연도 비교 → 감소한 해 확인 → 날씨 결합 순서입니다.
- 문서 검색은 공개 프로젝트 Markdown 문서만 읽습니다. 설정 파일과 키를 읽지 않습니다.
- 인터넷 검색이 막히면 실패를 알리고 직접 열 수 있는 검색 링크를 제공합니다.
- 이익 비교는 최초 단가에 각 변동률을 적용하며 판매량·비용은 고정합니다.
- 이익 비교의 예시 질문은 판매량 1,000kg, 단가 4,000원/kg, 총비용 300만원을 연습용으로 사용합니다.
  직접 계산하려면 ‘판매량 1000kg, 단가 4000원, 총비용 300만원일 때 가격이 10%, 20% 내려가면?’처럼 적어 주세요.
