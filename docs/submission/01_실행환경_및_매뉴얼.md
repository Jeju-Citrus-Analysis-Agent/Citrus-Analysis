이 문서는 프로그램을 설치하고, 데이터를 준비하고, 화면·분석 노트북·테스트를 실행하는 방법을 순서대로 설명합니다.

## 1. 구성

| 폴더 | 내용 |

## 2. 실행 환경

| 항목 | 검증한 환경 |
| --- | --- |
| 운영체제 | Ubuntu 24.04 (Windows 11 WSL2). Windows에서는 동봉된 `.cmd` 파일로 실행 |
| Python | 3.10 (3.10.22에서 검증) |
| 가상환경 | conda (`environment.yml`) 또는 Python venv |
| 주요 패키지 | pandas 2.3, matplotlib, seaborn, openpyxl, streamlit 1.65, altair, fpdf2, anthropic (선택) |

## 3. 설치

### 3.1 conda (권장)
```bash
# 프로젝트 폴더에서
conda env create -f environment.yml        # Python 3.10 + 분석 패키지 + 프로젝트 패키지(편집 모드)
conda activate jeju_citrus
pip install -r citrus_freellm/requirements-ui.txt   # 웹 화면·리포트 (streamlit, fpdf2, anthropic)
python -m ipykernel install --user --name jeju_citrus   # 노트북용 커널 등록 (노트북을 쓸 때만)
```

### 3.2 Windows (venv)
```powershell
py -3.10 -m venv .venv-agent
.\.venv-agent\Scripts\python.exe -m pip install -r requirements.txt -r citrus_freellm\requirements-ui.txt
.\.venv-agent\Scripts\python.exe -m pip install -e .
```
`citrus_freellm\start-web.cmd`는 `.venv-agent`가 있으면 자동으로 그 환경을 씁니다.

### 3.3 (선택) Claude 상담 모드
API 키가 없어도 모든 조회·분석 기능이 동작합니다. 키를 넣으면 "창업하려는데 어떤 품종이 좋아?"처럼 조건이 애매한 질문에 Claude가 조건을 되물으며 상담합니다. 숫자는 이때도 로컬의 검증된 조회 결과에서만 가져오고, 답의 모든 숫자를 조회 결과와 자동으로 대조합니다.

```bash
cp citrus_freellm/.env.example citrus_freellm/.env
# .env 파일에서 ANTHROPIC_API_KEY= 뒤에 키를 붙여 넣기 (기본 모델 claude-haiku-5-5)
```
`.env`는 저장소·제출본에서 제외됩니다.

## 4. 데이터 준비

### 4.1 제출본에 들어 있는 데이터
바로 쓸 수 있습니다: 제주데이터허브 과수·특용작물 통계, 기상청 ASOS 기상 자료, 소비자물가지수, KOSIS 농가구입가격지수.
이 데이터만으로도 화면이 실행되고, 과수 생산량 조회·기상 분석 설명·자료 안내가 동작합니다.

### 4.2 제주농산물수급관리센터 자료 (직접 받아야 함)
수급센터 자료는 이용약관상 사전 승낙 없는 복제·유통이 금지되어 제출본에 넣지 않았습니다. 아래 순서로 받으면 같은 파일이 만들어집니다. 이 자료가 없을 때 관련 질문에는 "필요한 자료가 없습니다 … 매뉴얼의 「데이터 준비」 절차로 받아 주세요"라고 안내하고, 관련 자동 검사는 실패 대신 이유를 밝히고 건너뜁니다.

| 순서 | 자료 | 방법 | 넣을 위치 (파일 이름 규칙) |
| --- | --- | --- | --- |
| ① | 감귤 생산정보·가공·수출 통계 | `python scripts/collect_jasdc.py` (자동 수집 + 정제) | `data/raw/jasdc/`, 정제 결과는 `data/processed/citrus_*.csv` |
| ② | 일별 가격·출하 | 가격 정보의 '총괄가격'(도매시장/직거래, 일별) 화면에서 '조회 자료 엑셀 다운로드' (시즌별) | `data/raw/jasdc_manual/price_daily/price_whole_{품종}_{시작일}-{끝일}.xlsx` (예: `price_whole_노지온주_20241001-20251001.xlsx`) |
| ③ | 월별 상자규격 가격 | '단위별(월별) 가격'(상자 규격별) 화면의 표를 복사해 텍스트로 저장 | `data/raw/jasdc_manual/price_monthly_box/price_monthly_box_{품종}_{시즌}.txt` |
| ④ | 유통처리 상황 | 감귤 > 일일정보 > 유통처리 상황 화면 표를 엑셀 시트 5개로 옮김 (`노지온주_연도별`, `노지온주_2025_월별`, `노지온주_2025_도매시장별`, `노지온주_크기별가격`, `품종별_유통처리비교`) | `data/raw/distribution/distribution_analysis.xlsx` |
| ⑤ | 표준소득 분석표 | 알림공간 > 센터간행물에서 「○○년산 감귤유통처리 분석」 PDF를 받음. 스캔본인 2016·2018~2021년산은 표를 보고 `standard_income_transcribed.csv`에 옮김 (컬럼: 산지연도, 원문분류, PDF쪽, 수량_kg_10a, 단가_원_kg, 총수입, 중간재비, 경영비, 자가노동시간, 자가노동비, 유동자본, 고정자본, 토지자본, 생산비, 소득, 비고) | PDF: `data/raw/jasdc_manual/reports/distribution_analysis_{산지연도}.pdf`, 옮긴 표: `data/external/cost/` |

받은 뒤 정제 결과를 만듭니다.
```bash
python scripts/collect_jasdc.py --skip-download   # ②·③ 수동 자료 정제 (①을 이미 받았다면 다운로드 생략)
python scripts/make_dataset.py                    # ④ 유통처리 엑셀·기상·품질 정제 → processed, interim
pip install pypdf && python scripts/extract_standard_income.py   # ⑤ 표준소득표 → data/external/cost/
python scripts/check_quality.py                   # 품질 이슈 확인 근거 출력 (선택)
```

## 5. 실행

### 5.1 웹 화면 (에이전트)
```bash
python -m streamlit run citrus_freellm/web.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```
Windows에서는 `citrus_freellm\start-web.cmd`를 더블클릭해도 됩니다. 브라우저에서 http://127.0.0.1:8501 을 엽니다.

사용 순서
1. 시작 화면의 귤을 누르면 메인 화면으로 들어갑니다.
2. 추천 질문 버튼을 누르거나, 입력칸에 질문을 적고 질문하기를 누릅니다. 연도·품종·항목을 함께 적으면 정확합니다. 예: "2020년 천혜향 생산량 알려줘", "2024년산 품종별 소득 비교해줘", "노지온주 손익분기 단가 보여줘", "언제 팔면 비싼가?"
3. 답은 결론, 세부 설명(표·근거·출처) 순서로 나옵니다. 긴 설명은 '자세히 보기'에 접혀 있습니다.
4. 표가 나온 뒤 "그래프로 그려줘"라고 하면 같은 수치로 그래프를 그리고, "막대그래프로 바꿔줘"처럼 모양(막대·꺾은선·영역·점)을 바꿀 수 있습니다.
5. 질문 아래 수정하기로 질문을 고치면 그 자리부터 다시 답합니다.
6. 위쪽 버튼: 새 대화(대화·조건 초기화), 예시 질문(목적별 질문 모음), 리포트(결과를 PDF·Markdown으로 내려받기), 사용 안내.

답하지 않는 것: 미래 값 예측(내년 가격 등)과 원인 단정은 하지 않습니다. 이런 질문에는 이유를 밝히고 지난 기록으로 답할 수 있는 질문을 제안합니다.

### 5.2 터미널에서 질문하기
```bash
python -m citrus_freellm "천혜향 생산량을 그래프로 보여줘"   # 질문 한 번
python -m citrus_freellm                                      # 대화 모드
python -m citrus_freellm --diagnose                           # 자료·환경 점검
```

### 5.3 분석 노트북
`notebooks/01_eda.ipynb` ~ `04_breakeven_decomposition.ipynb`를 Jupyter 또는 VSCode에서 `jeju_citrus` 커널로 열고 위에서부터 실행합니다. 한 노트북은 5초 안팎이면 끝까지 실행됩니다.

### 5.4 자동 검사
```bash
python -m pytest -q tests                  # 데이터 정제·품질 검사 52개
python -m pytest -q citrus_freellm/tests   # 에이전트·화면 검사 263개 (유료 모델을 부르지 않음)
python -m citrus_freellm.evaluate --local  # 경영비·손익분기 질문 16개 오프라인 평가
```
2026-11-18 검증 결과: 데이터 52개, 에이전트 263개 모두 통과, 오프라인 평가 16/16, 노트북 4개 모두 오류 없이 실행. 수급센터 자료가 없는 상태(제출본 그대로)에서는 데이터 36개·에이전트 249개 통과, 나머지는 자료 없음으로 건너뜀.

## 6. 문제 해결

| 증상 | 해결 |
| --- | --- |
| `crop_production.csv`의 한글이 깨져 보임 | 파일이 cp949 인코딩이라 그렇습니다. 코드는 자동으로 처리합니다. VSCode에서는 오른쪽 아래 인코딩을 눌러 `Korean (EUC-KR)`으로 다시 열기 |
| "필요한 자료가 없습니다" | 4.2의 수급센터 자료를 받고 정제 명령을 실행 |
| 8501 포트를 이미 사용 중 | 실행 명령에 `--server.port 8502`를 붙이고 http://127.0.0.1:8502 로 접속 |
| 리포트가 Markdown만 만들어짐 | PDF용 한글 글꼴을 찾지 못한 경우입니다. 환경 변수 `CITRUS_PDF_FONT`(굵은 글꼴은 `CITRUS_PDF_FONT_BOLD`)에 한글 TTF 경로를 지정 |
| 화면 색·배치가 다르게 보임 | Streamlit이 1.65가 아닌 경우입니다. `pip install -r citrus_freellm/requirements-ui.txt`로 다시 설치 |
| 상담 모드가 켜지지 않음 | `citrus_freellm/.env`의 `ANTHROPIC_API_KEY` 줄에 키가 있는지 확인한 뒤 서버를 다시 시작 |
