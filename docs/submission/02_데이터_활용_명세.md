# 데이터 활용 명세서

| 과제명 | 감귤의 신(神), 데이터로 읽는 제주 감귤 수급 비서 |
| --- | --- |
| 팀 | 알맹이 (김태양, 오동경, 류채연) |
| 작성일 | 2026년 11월 19일 |

이 문서는 프로젝트가 사용하는 데이터의 출처·이용 조건, 가공 과정, 데이터셋별 구성(컬럼·단위·기간), 품질 이슈와 처리 방법, 그리고 각 데이터가 어떤 분석·기능에 쓰이는지를 정리합니다. 4장의 행 수·기간·컬럼은 실제 파일에서 자동으로 뽑았습니다.

## 1. 데이터 출처와 이용 조건

| 출처 | 데이터 | 수집 방법 | 이용 조건 | 제출본 포함 |
| --- | --- | --- | --- | --- |
| 제주농산물수급관리센터 ([jasdc.or.kr](https://jasdc.or.kr)) | 감귤 생산정보·가공·수출 통계표 | `scripts/collect_jasdc.py` 자동 수집 | 이용약관상 사전 승낙 없는 복제·유통·상업적 이용 금지 | 미포함 (수집 절차만 제공) |
| 〃 가격·출하 화면 | 일별 출하량·가격, 월별 상자규격 가격 | 화면의 '엑셀 다운로드'로 수동 수집 | 〃 | 미포함 |
| 〃 유통처리 상황 화면 | 노지온주·하우스·월동·만감류 유통처리 표 | 화면 표를 엑셀 5개 시트로 옮김 | 〃 | 미포함 |

| 제주데이터허브 ([jejudatahub.net](https://jejudatahub.net)) | 제주 과수 품종별 생산 통계, 시도별 특용작물 생산현황 | 파일 내려받기 | 제주데이터허브 이용약관 | 포함 |
| 기상청 기상자료개방포털 (ASOS) | 제주·고산·성산·서귀포 일자료 | 수동 내려받기 | 공공누리 (출처 표시) | 포함 |
| 국가통계 소비자물가조사 | 연평균 CPI (2020=100) | 공식 표에서 옮김, `검증상태` 컬럼으로 대조 기록 | 공공누리 (출처 표시) | 포함 |
| KOSIS 농가판매 및 구입가격조사 | 농가구입가격지수 (분기, 2020=100) | KOSIS에서 CSV 내려받기 | 공공누리 (출처 표시) | 포함 |

> 제주농산물수급관리센터 자료를 제출본에 넣지 않은 이유: 이용약관이 사전 승낙 없는 복제·유통을 금지합니다. 그래서 저장소와 제출본에는 수집·정제 코드와 절차만 담았습니다. 실행 매뉴얼의 「데이터 준비」를 따르면 같은 파일을 다시 만들 수 있고, 자료가 없을 때 에이전트는 멈추지 않고 "자료가 없다"는 안내를 보여 줍니다. 보고서에 인용한 수치는 모두 출처를 밝혔습니다.

## 2. 데이터 흐름

```
data/raw/        받은 그대로 보관 (읽기 전용, 형식도 바꾸지 않음)
   │  src/jeju_citrus/data/ 의 정제 코드 (scripts/make_dataset.py, collect_jasdc.py)
   ▼
data/interim/    품질 이슈(Q3~Q5)를 바로잡은 중간 결과
data/processed/  분석·에이전트가 읽는 최종 CSV (UTF-8, 단위는 컬럼명 접미사: _톤, _원_kg, _백만원 …)
data/external/   외부 참고 자료 (표준소득표, CPI, 농가구입가격지수, 기상 원본)
   │
   ├─▶ notebooks/01~04   탐색·추세·경영비·손익분기 분석
   └─▶ citrus_freellm/   질의응답 에이전트 (검증된 로컬 조회로만 숫자를 답함)
```

- 모든 경로는 `src/jeju_citrus/config.py` 한 곳에서 정의합니다.
- 정제 결과는 다시 만들어도 똑같이 나옵니다. 2026-11-18에 `make_dataset.py`를 다시 실행해 기존 파일과 바이트 단위로 같음을 확인했습니다.

## 4. 데이터셋별 상세

컬럼 단위·설명은 `citrus_freellm/data_definitions.json`에 정의된 경우 그대로 옮겼고, 나머지는 컬럼명 접미사(`_톤`, `_원_kg` 등)에서 읽었습니다.

### 4.1 제주 과수 품종별 생산 통계 (원본)

- 파일: `data/raw/public/fruit_production.csv`  
- 규모: 144행 × 5열, 기간: 2015 ~ 2020 (기준연도)  
- 만드는 코드: `원본`  ·  제출본: 포함 (저장소에 있음, 이용약관 확인 필요)  
- 단위(행 하나): 원본은 기준연도 × 품종대분류 × 품종소분류. 정제 후 연도 × 정규화 품종. 감귤 재배형태와 만감류 세부 품종은 집계수준이 달라 합산 금지  
- 에이전트 활용: 생산량·생산면적 조회·비교, 동일 집계수준 순위, 연도 평균 지원  

| 컬럼 | 단위 | 설명 |
| --- | --- | --- |
| 기준연도 | 년 | 원자료의 기준연도 |
| 품종대분류 | - | 원본 분류. 일부 연도 오기가 있어 그대로 집계하지 않음 |
| 품종소분류 | - | 원본 품종명 또는 재배형태. 정제 시 기타 명칭 보정 |
| 생산면적(ha) | ha | 원자료에 생산면적으로 기재된 면적. 수확·재배면적과의 포함관계 및 상세 산정 기준 미확인 |
| 생산량(톤) | 톤 | 해당 연도·품종의 원자료 생산량. 출하량·처리량·판매량으로 간주하지 않음 |

주의할 점: 2017년 면적 통계 단절: 이를 가로지르는 면적·면적당 지표 직접 비교 금지 / 원본 대분류 오기와 만감류/기타 명칭은 정제 함수에서 보정 / 생산면적이 수확면적 또는 재배면적과 같은 정의라는 근거는 확인되지 않음

| Q9 | citrus_production_yearly | 2017년 재배면적 통계 단절(만감류 면적 급증, 생산량은 그대로) | 2016↔2017년을 가로지르는 면적·ha당 비교 금지 |
| Q10 | jasdc vs noji_yearly | 생산량과 처리량은 다른 지표 | 컬럼명으로 구분, 섞지 않음 |
| Q11 | 일별 vs 월별 상자규격 가격 | 물량 차이 1.75배 | 가격은 같은 출처(비율 0.995~1.004)라 함께 써도 되고, 물량은 섞지 않음 |

### 5.1 표준소득표 추출과 검증
- 2017·2022~2024년산은 PDF 표를 코드로 추출하고, 2016·2018~2021년산은 스캔본·글꼴 깨짐이라 쪽 이미지를 보고 옮겼습니다(`standard_income_transcribed.csv`, 원문 오기 2건 정정).
- 모든 행에서 소득 = 총수입 − 경영비, 순수익 = 총수입 − 생산비(±1원), 만원 열 = 원 열 ÷ 10,000이 맞는지 검사합니다. 하나라도 어긋나면 에이전트가 답을 내지 않습니다.
- 표준소득표는 표본 농가 기준입니다. 만감류는 표준표 총수입이 제주 평균의 1.14~3.71배라, 평균 농가 소득으로 읽으면 과대평가됩니다.

### 5.2 물가 보정
- 단가·소득은 CPI(2020=100)로 실질화했습니다. 2015년 이후는 공식 값과 일치, 2004~2014년은 제3자 표를 공식 상승률로 대조했습니다(`검증상태` 컬럼).
- 농사 비용 쪽 물가는 소비자물가와 다르므로, KOSIS 농가구입가격지수를 2024년 노지 경영비 항목 비중으로 가중한 경영비 물가지수를 따로 만들었습니다.
