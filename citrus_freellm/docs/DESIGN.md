# 실행·검증 설계

## 같은 엔진을 사용하는 두 화면

CLI(__main__.py)와 웹(web.py)은 동일한 Agent를 사용합니다. 웹은 세션마다 Agent를 만들며
전역 캐시로 다른 브라우저의 대화와 섞지 않습니다. 화면 재실행·다운로드로 질문을 중복 처리하지 않습니다.

Agent의 처리 순서: 명령/자료 안내 → 로컬 가정 계산 → 분석 근거 설명 → 명시적 품종 분석 →
단일 품종 조건/의도 해석 → 허용 도구 선택 → 원자료 검증 → 성공 결과 기록입니다.
새 UI에서 계산·검색·검증 코드를 별도로 구현하지 않습니다.

## 근거별 책임

- tools.py: 참조 프로젝트의 정제 규칙으로 생산량·면적을 조회합니다. catalog·production만 노출합니다.
- guardrails.py: 질문 조건·기간·품종·단위·집계수준·중복·결측을 검증하고 답변을 만듭니다.
- reference_check.py: pandas 정제와 분리된 표준 CSV/Decimal 읽기로 원자료를 독립 대조합니다.
- analysis.py: 명시적 품종 비교·순위·연도 평균을 계산하고 원자료 기반 재계산과 대조합니다.
- intent.py: 모델의 제한된 의도 제안을 검사하고 상대 연도는 코드로 계산합니다.
- insights.py: 검토된 다섯 분석 주제를 검색합니다. 모델은 필요한 경우 주제만 선택합니다.
- scenarios.py: 사용자 가정의 단위·값을 확인하고 전후 매출·잔여액·손익분기를 로컬에서 계산합니다.
- reporting.py: 성공 결과만 HTML·Markdown·JSON으로 저장합니다. 웹도 같은 함수를 사용합니다.
- repository.py: 형제 폴더/저장소 내부 배치를 지원하고 정제 모듈 경로의 중복 삽입을 막습니다.

원자료와의 일치를 확인할 뿐, 원자료 자체의 오류나 조회 전에 발생한 변경을 판별하는 외부 공인 기준은 아닙니다.
생산면적·수확면적의 정의를 같다고 단정하지 않고 2017년 면적 통계 단절을 가로지르는 계산은 보류합니다.

## 공개 분석 근거

knowledge/sources/public_analysis.md는 기존 공개 README와 분석 노트북의 Markdown 발췌입니다.
내부 Slack 문서·회원 정보·메시지·이미지와 원자료 CSV는 포함하지 않습니다.
출처 커밋을 고정하고, cards.json의 주장·한계와 manifest.json의 SHA-256을 함께 관리합니다.
실행 시 해시와 인용 구절을 확인하며 바뀌면 보류합니다. 해시를 실행 중 자동 갱신하지 않습니다.
문서의 일치는 분석 자체의 정확성까지 증명하지 않습니다.

현재 분석 설명은 면적당 매출·출하 시기·물량과 가격·기상 관계·2026년산 시장 기록의 다섯 주제입니다.
원자료를 새로 계산한 답변과 문서 요약을 구분합니다. 상관·회귀 기울기를 인과효과 또는 미래 공식으로 쓰지 않습니다.
다른 품종에 노지온주 결론을 적용하지 않고, 비용 없는 매출 순위를 순이익 순위로 바꾸지 않습니다.

## 가정 계산과 상태

판매가능수량 kg/톤, 단가 원/kg, 같은 대상·기간의 총비용/경영비 원을 사용합니다.
매출 = 수량 × 단가, 잔여액 = 매출 − 지정 비용, 손익분기단가 = 지정 비용 ÷ 수량입니다.
누락 조건·음수·비정상 수치·0 수량·모호한 단위는 보류합니다. 생산량을 판매량으로 간주하지 않습니다.
변동률은 표시된 최초 기준에 적용하며 누적하지 않습니다. 비용 누락 시 완전한 순이익으로 부르지 않습니다.
실제 농가 실적·미래 예측이 아닌 가정 계산으로 표시합니다.

새 대화는 조회·설명·가정 조건과 리포트 대상 기록을 지웁니다. 이미 저장한 파일은 유지합니다.
기존 조회는 최근 성공 조건을 이어받으며 실패한 요청은 조건을 바꾸지 않습니다.
현재 여러 품종 분석 후의 모호한 후속 질문, 부분 가정의 다중 턴 수집, 자동 최적화는 지원하지 않습니다.

## 외부 전송·공유

인식된 가정 계산의 금액·수량과 분석 원문은 외부 모델에 보내지 않습니다.
일반 조회·의도 해석에는 현재 질문·검증된 이전 조회 조건이 공급자에게 전송될 수 있습니다.
이전 대화 전체는 첨부하지 않습니다. 모델 응답이나 서버의 오류 본문에서 키를 출력하지 않습니다.

.gitignore는 실제 .env/백업·로그인 정보·runtime·로그·리포트·가상환경·캐시를 제외합니다.
서버/공급자 설정은 각자 준비하며 .env.example에는 자신의 키를 넣어 커밋하지 않습니다.
로컬 화면만 바인딩합니다. 공개 서비스 인증·영구 대화 저장·서버 자동 설치는 이번 범위가 아닙니다.
