# 도구별 쉬운 질문

API 키는 필요 없습니다. 인터넷 자료 찾기만 인터넷 연결이 필요합니다.
웹 화면 왼쪽 **예시 질문 → 무엇을 하고 싶으세요?**에서 카테고리를 선택하고 같은 질문을 눌러 볼 수 있습니다.

| 도구 | 질문 1 | 질문 2 |
|---|---|---|
| 인사와 쉬운 설명 | 안녕 | 생산량과 출하량은 뭐가 달라? |
| 여러 자료 보기 | 2020년 제주 날씨 보여줘 | 2020년 수출 자료 보여줘 |
| 그래프 그리기 | 천혜향 생산량을 그래프로 보여줘 | 한라봉 생산량 그래프 그려줘 |
| 자료를 한 표로 보기 | 천혜향 생산량과 기온을 한 표로 보여줘 | 한라봉 생산량과 강수량을 같이 보여줘 |
| 문서에서 찾기 | 문서에서 2017년 면적을 찾아줘 | 문서에서 출하 시기를 찾아줘 |
| 인터넷 자료 찾기 | 인터넷에서 감귤 통계 찾아줘 | 인터넷에서 감귤 출하 자료 찾아줘 |
| 날씨와 생산량 비교 | 기온과 천혜향 생산량은 관계가 있어? | 강수량과 한라봉 생산량은 관계가 있어? |
| 가격별 이익 비교 | 가격이 내려갈 때 이익을 예시로 보여줘 | 가격이 오를 때 이익을 예시로 보여줘 |
| 차례대로 살펴보기 | 천혜향 생산량을 차례대로 살펴봐줘 | 한라봉 생산량을 순서대로 확인해줘 |

## 알아두세요

- 인사·용어 설명은 준비된 답변을 사용합니다. 자유로운 AI 대화는 아닙니다.
- 그래프와 생산량·날씨 결합은 2015~2020년 과수 원자료를 사용합니다.
- 날씨는 제주 관측소 기준입니다. 관계 분석은 원인·미래 예측을 뜻하지 않습니다.
- 단계별 조사는 원자료 확인 → 연도 비교 → 감소한 해 확인 → 날씨 결합 순서입니다.
- 문서 검색은 공개 프로젝트 Markdown 문서만 읽습니다. 설정 파일과 키를 읽지 않습니다.
- 인터넷 검색이 막히면 실패를 알리고 직접 열 수 있는 검색 링크를 제공합니다.
- 이익 비교는 최초 단가에 각 변동률을 적용하며 판매량·비용은 고정합니다.
- 이익 비교의 예시 질문은 판매량 1,000kg, 단가 4,000원/kg, 총비용 300만원을 연습용으로 사용합니다.
  직접 계산하려면 ‘판매량 1000kg, 단가 4000원, 총비용 300만원일 때 가격이 10%, 20% 내려가면?’처럼 적어 주세요.
